# Demo Landing Page para Negocios Locales

Plantilla web de alta conversion para clinicas odontologicas y servicios medicos locales.
Optimizada para dispositivos moviles con boton directo a WhatsApp, catalogo de especialidades y formulario interactivo de reserva.

## Caracteristicas
- Diseno responsive mobile-first desarrollado con HTML5 y Tailwind CSS.
- Integracion directa con WhatsApp Click-to-Chat para agendamiento inmediato.
- Secciones estructuradas: Hero con propuesta de valor, tratamientos destacados, prueba social, ubicacion y preguntas frecuentes.
- 0 dependencias complejas, carga ultrarrapida y costo 0 de servidores.

## Despliegue
Alojado de forma gratuita y continua en GitHub Pages.
